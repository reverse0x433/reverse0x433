# Hi, I'm Anurag 👋

Backend developer focused on building reliable server-side systems. Interested in cybersecurity and cloud infrastructure.

I work primarily in Python, building backend APIs and services with Flask and PostgreSQL. My focus is on writing well-structured, secure server-side code — designing authentication flows, modeling data, and thinking about how systems fail. Alongside development, I practice offensive security through CTFs and structured learning platforms, applying what I learn back into the apps I build. I'm currently expanding into cloud infrastructure with AWS.
